# Claude Code in this repository

Read by Claude Code at the start of every session, for everyone who works here.

How decisions are made, the standards every change is held to, and how pull requests work are
in [CONTRIBUTING.md](CONTRIBUTING.md). They apply to changes drafted with Claude Code exactly as
to any other.

## Attribution

- **End every pull request description, review, and pull request or issue comment with:**

  ```text
  🤖 Co-Authored-By [Claude Code](https://claude.com/claude-code)
  ```

  Never "Generated with Claude Code". The maintainers review every change and make every
  decision; an assistant drafts. "Co-Authored-By" says that, and "Generated with" does not.
- **Commit messages keep their trailer:** `Co-Authored-By: Claude <model> <noreply@anthropic.com>`.
